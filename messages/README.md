# Messages

Bot comments are defined here as Markdown so they can be customized without touching workflow code.

## How it works

- Each file is one bot comment, identified by its filename without `.md`
  (e.g. `duplicate-request.md` -> message key `duplicate-request`).
- The first line names the hidden marker used to find and update the comment later:

  ```md
  <!-- marker: duplicate-request -->
  ```

  Change the marker only if you also intend to abandon existing bot comments (they are matched by marker text).

- `{{ placeholders }}` are replaced at render time. Unfilled placeholders are left as-is so nothing is lost silently.
- Rendering is handled by `utils/messages.cjs` and wraps the output in the marker comment automatically.

## Available messages

| Key                      | Used by                       | Placeholders    |
| ------------------------ | ----------------------------- | --------------- |
| `duplicate-request`      | `pr.yml` duplicate check      | `{{conflicts}}` |
| `incomplete-pr-template` | `utils/check-pr-template.cjs` | `{{errors}}`    |

## Placeholder syntax

- `{{name}}` is replaced with `vars.name`.
- `{{a.b}}` reads nested values.
- Keep the marker line exact; it is generated by `utils/messages.cjs` as `<!-- has-a-link-bot: <marker> -->`.

## Adding a new message

1. Create `messages/<key>.md` starting with a marker comment.
2. Call `renderMessage("<key>", { ... })` from the relevant script or workflow.

## Security note

Message files are read by the privileged `pr.yml` workflow from the **default branch**, not from the pull request. Only maintainers who can push to `main` can change bot output.
